# 联调前检查清单

这份清单对应`接口协议_v0.2.1.md`和`三人任务单_v0.2.1.md`。它用于确认
三组可以开始互接，不代表真实机器人已经通过安全或性能验收。

## B 组主控 / Mock

- [x] `DriveCommand` 归一化参数、TTL、时间戳和 request ID 校验。
- [x] 重复运动请求幂等，重复请求不会延长有效期；不同 payload 返回`CONFLICT`。
- [x] `SAFE/AUTO/REMOTE`只能按显式 SAFE 中转规则切换。
- [x] 独立`MotionWatchdog.check()`及 daemon 调度入口；过期后锁定 SAFE。
- [x] 底盘与机械臂互锁，动作超时保留安全锁。
- [x] Mock FSM 跑通黑牌报警→击倒请求→找球→投杯→返航，以及黄牌绕行分支。
- [x] 蜂鸣器是独立辅助服务，未写入 Motion/Arm 公共接口。

## A/C 交接前置条件

- [ ] A 提供只依赖公共`VisionResult`的离线实现和样例；未标定距离保持`None`。
- [ ] A 明确黑线/黑牌混淆、过期帧和无目标的测试结果。
- [ ] C 提供`ActionAck.action_id`、异步状态轮询、取消和超时锁的契约测试。
- [ ] B 仅依据`DONE_UNVERIFIED`调度后续步骤，不把动作完成当作实物成功。

## 实机接入前必须补齐

- [ ] 记录平台型号、固件、SDK 版本和真实支持的组合运动能力。
- [ ] 测量坐标、速度/步幅映射、报警距离和机械臂预设；更新配置，不改写公共单位约定。
- [ ] 验证下位机失联自动停车、物理急停和机械臂取消能力；Mock 结果不能替代实测。
- [ ] 在场地上执行 SAFE→AUTO→SAFE→REMOTE 的现场确认流程，保留日志和负责人签字。
